## Organização das contribuições

As atividades são registradas em issues. As alterações são propostas em branches separadas e enviadas por pull requests para revisão.

O repositório utiliza o CodeRabbit para revisão automática e exige duas aprovações de colegas para integrar alterações à branch principal, além das demais verificações configuradas.

As responsabilidades e as entregas de cada participante podem ser acompanhadas pelas [issues](https://github.com/bfontanayasmin/projeto-ed-final/issues) e [pull requests](https://github.com/bfontanayasmin/projeto-ed-final/pulls) do projeto.
