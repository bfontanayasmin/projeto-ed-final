# Acidentes nas rodovias federais brasileiras

Dados públicos da PRF como ponto de partida para uma pipeline de dados e análises sobre segurança nas rodovias.

</div>

## Objetivo

Construir uma pipeline sobre acidentes nas rodovias federais brasileiras, desde a organização dos registros em um banco normalizado até a disponibilização de informações para análise.

O projeto busca analisar a ocorrência e a gravidade dos acidentes em diferentes períodos e localidades. A utilidade pública está em facilitar a compreensão desses registros e apoiar discussões sobre segurança viária.
