# Teste de revisão automática

Este pull request verifica a integração do CodeRabbit.

O fluxo de colaboração do projeto será:
1. Criar uma branch para a tarefa.
2. Abrir um pull request.
3. Aguardar a revisão automática e avaliar os comentários.
4. Obter a aprovação de dois colegas.
5. Realizar o merge após atender às regras do repositório.
